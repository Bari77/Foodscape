Casier I · Apéritif

Le Masque

« Celui qui sourit derrière la soie rouge… »

Au bal, trois invités portaient un masque rouge. L’un d’eux a quitté la piste de danse exactement quand les chandeliers ont cligné — six fois.

Sur le carton d’invitation glissé dans votre kit, comptez les lettres du prénom de l’hôtesse. Soustrayez le nombre de clignements. Le résultat ouvre le premier cadenas.

Indice

Le prénom est écrit en majuscules dorées sur le carton. Les clignements : vous les avez déjà lus ci-dessus.
