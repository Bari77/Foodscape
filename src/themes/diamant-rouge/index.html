Prologue

Paris, hôtel particulier, 1925

Sous les lustres, le tout-Paris danse derrière des masques de soie. À minuit, le diamant rouge — rubis légendaire de la famille Valois — disparaît de son écrin. Personne n’a quitté le bal. Tout le monde est suspect.

Votre glacière contient trois casiers cadenassés. Les QR codes dispersés dans le jeu mènent ici : des indices, jamais le code entier. Observez, croisez, déduisez — puis goûtez.
